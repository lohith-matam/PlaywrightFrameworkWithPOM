
## Documentation

This is a web automation framework built with Playwright, JavaScript, and the Page Object Model (POM) design pattern.

## Run Locally

Clone the project

```bash
  git clone https://github.com/lohithmutt/PlaywrightFrameworkWithPOM.git
```

Go to the project directory

```bash
  cd PlaywrightFrameworkWithPOM
```

Install dependencies

```bash
  npm install
```

To Run the tests

```bash
  npm run CucumberRegression
  npm run WebTests
  npm run APITests
```
